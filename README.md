# HabitFlow 网页版

## 内容
- index.html：网页应用
- manifest.webmanifest：添加到主屏幕配置
- sw.js：离线缓存（需 HTTPS 网站环境）

## 使用
1. 将整个文件夹部署到支持 HTTPS 的静态网站托管服务。
2. 用华为浏览器打开网站。
3. 在浏览器菜单中选择“添加到桌面/添加到主屏幕”（菜单名称可能因版本不同）。
4. 数据保存在当前浏览器本地存储中。清理浏览器数据、换浏览器或换设备可能导致数据丢失，请定期备份或后续增加导出功能。

## 当前版本说明
这是首个可用原型，数据仅保存在本机浏览器，不含云同步、账号、通知或云端 AI。年度热力图按年度 364 天窗口绘制；连续天数按每日全部活跃习惯完成计算。建议先实际试用，再继续增加数据导出/导入、目标频率和原生鸿蒙版本。
